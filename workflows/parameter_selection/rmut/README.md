# RMUT parameter selection

`select_rmut_parameters.R` implements RMUT parameter selection using the eight
fixed H0/H1-standard calibration PP-path inputs under `inputs/calibration_pp/`.
Their relative paths, SHA-256 and MD5 identities are recorded in
`inputs/calibration_pp/input_manifest.csv`. H1-observed is excluded from selection.

Run from the repository root. With no arguments, or with `--help`, the entry
prints usage without loading the PP inputs or performing calculations:

```text
Rscript workflows/parameter_selection/rmut/select_rmut_parameters.R
Rscript workflows/parameter_selection/rmut/select_rmut_parameters.R --help
```

An explicit full-grid rescreen uses the supplied fixed PP inputs and writes
new results outside the repository:

```text
Rscript workflows/parameter_selection/rmut/select_rmut_parameters.R rescreen /path/to/new_external_selection
```

Omit case arguments to rescreen all four cases, or append one or more of
`IMpower`, `KEYNOTE598`, `OAK` and `survival_colon`. The existing selection
rules and full-grid calculations are unchanged. A four-case run produces
four `eligible_<case>.tsv` candidate tables, four `selected_<case>.tsv` final
selections, paired-MCSE diagnostics and `RMUT_LOCKED_PARAMETERS.tsv`.

Saved eligible and selected reference tables are not bundled in this GitHub
distribution. To verify tables generated by `rescreen`, or obtained from an
existing results archive, pass their directory explicitly. No submission-package
layout is required:

```text
Rscript workflows/parameter_selection/rmut/select_rmut_parameters.R verify --reference-dir /path/to/external_selection
Rscript workflows/parameter_selection/rmut/select_rmut_parameters.R verify --reference-dir /path/to/external_selection --output-dir /path/to/new_external_verification
```

The reference directory must contain the four `eligible_<case>.tsv` and four
`selected_<case>.tsv` tables. Relative reference paths resolve from the current
working directory, and paths containing spaces should be quoted.
`--reference-dir=DIR` and `--output-dir=DIR` are also accepted. The optional output
directory may alternatively be supplied as one positional argument after `verify`;
it must not be supplied a second time through `--output-dir`.

Verification checks the supplied candidate metrics against the fixed PP paths
and reapplies the paired-MCSE selection rule within that saved candidate set.
It does not establish that the saved set covers the complete grid; use
`rescreen` for the full search. Without `--output-dir`, verification prints its
summary and writes no files. With an output directory, it additionally writes
the verification summary, paired-MCSE details and calculation metadata.
Output directories must be new and outside the repository.

Neither mode generates patients or fits models. The fixed PP inputs are numerical
postprocessing inputs, not fitted model objects or posterior draws.
